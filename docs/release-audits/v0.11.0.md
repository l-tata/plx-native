## Compatibility tiers, and what moved

Nothing moved. No television ran this version, so no playback line is claimed, and the startup tier rests on the generated firmware check below. No FFI, linkage, Starfish, ACB, curl or FFmpeg binding changed since v0.10.0.

## Known issues at release, with provenance

- **Mid-stream frame-rate change on a Tunarr channel.** Known from the design (`docs/live-tv-plan.md`, risk 2): the frame rate is probed once at tune. Not measured. Tunarr's frame-rate normalisation avoids it.
- **The clock's and the guide's time zone** on a television whose native process sees UTC. Not measured.
- **Shuffle and play-queue continuation** (`POST /playQueues?shuffle=1`, `GET /playQueues/{id}`), **playlist queues**, the **Discover watchlist** calls and the section **filter values** are implemented from `docs/plex-openapi.json` and exercised only against the mock PMS.
- **Reopen where you left off** (`app::resume_place`) reverses upstream's deliberate retirement of the last-page bookmark (`7293b8bd`). It restores only after boot has settled on Home, only for the same profile and within 12 hours, and a key pressed during boot cancels it.
- **The ambient screensaver** assumes webOS does not blank a foreground native app (measured on webOS 4 on 2026-07-31, `boot.rs`); not measured on other versions.

## Deliberately not done

- The replay fixtures and documentation screenshots were not regenerated (as for v0.9.0).
- The webosbrew listing and the `webosbrew/apps-repo` submission belong to the upstream project and were not touched.

## Release configuration

| | |
|---|---|
| flavour | `com.beb.plxnative` (stable) — the id users install; `FLAVOR: stable` is pinned in the release workflow's build job |
| cargo features | `RELEASE=1`, which drops `devtools` and `devtriggers` |
| built by | GitHub Actions, from the tag, at a path identical on every runner |
| toolchain | webOS NDK unchanged, Rust nightly pinned by date in the `RUST_NIGHTLY` repository variable |

New outbound traffic since v0.10.0: plex.tv's Discover service for the profile's watchlist (read, add, remove, with the profile's own plex.tv credential); the Plex server's playlists, section filter values, shuffled and playlist PlayQueues and per-version media; and Tunarr's own channel logos and programme artwork over plain `http` on the configured Tunarr origin, cached in the app's image cache. New values in the session file: `auto_skip` and `screensaver`, both omitted at their defaults. New file: `<id>-resume.json` (the last place, its profile key and a timestamp), removed by Delete all data. No new payload file, and no toolchain or third-party dependency change. The fork's repository has no production telemetry variables, so this build compiles in no telemetry endpoint.
